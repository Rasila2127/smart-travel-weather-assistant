# Smart Travel & Weather Assistant

A Python-based project that provides country information and weather updates using REST APIs.

## Features
- Search for countries by name
- Get country details, including capital, currency, and flag
- View current weather information
- View a 5-day weather forecast with condition-based emojis
- Save, view, and delete destinations
- Get suggestions for misspelled country names

## Technologies Used
- Python
- REST APIs
- Requests library
- JSON
- Git and GitHub

## APIs Used
- Countries.dev — country information
- OpenWeatherMap — current weather and forecast

## Setup
1. Clone or download this repository.
2. Install the required library:
   `pip install requests python-dotenv`
3. Create a `.env` file and add your OpenWeatherMap API key.
4. Run `main.py`.

## Security
Keep your API key private. Never upload your `.env` file to GitHub.
